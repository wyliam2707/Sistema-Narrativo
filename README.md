# Sistema Narrativo

Este repositório separa **o motor do RPG** dos **dados de cada aventura**.

## Estrutura

- `sistema/` — regras universais, linguagem de fichas, agência de personagens e método para criar/organizar aventuras.
- `aventuras/` — cada aventura concreta, com seus personagens, mundo, relações, estado atual, cronologia, diretrizes de narração e história canônica.

## Regra fundamental

> **O sistema ensina como criar e operar. A aventura registra o que foi criado e o que aconteceu.**

Nada específico de uma campanha deve ser gravado como regra universal em `sistema/`.

Para iniciar ou continuar uma aventura, leia primeiro `sistema/00-LEIA-PRIMEIRO.md` e depois o `README.md` da aventura correspondente.
