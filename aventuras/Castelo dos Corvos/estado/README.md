# Estado

Esta pasta guarda os marcos operacionais de continuidade de `Castelo dos Corvos`.

`inicio.md` será o marco inicial aprovado antes da primeira cena. `atual.md` funcionará como savegame mutável com o ponto exato de continuação, STATUS e demais informações temporárias relevantes.

Não usar esta pasta para capítulos literários nem para fatos estáveis do cenário.
