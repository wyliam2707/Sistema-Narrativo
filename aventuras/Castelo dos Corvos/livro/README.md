# Livro

Esta pasta guarda os capítulos ou outro registro narrativo canônico consolidado de `Castelo dos Corvos`.

O conteúdo aqui deve conter apenas a versão válida da ficção, sem metacomunicação, tentativas descartadas ou instruções operacionais.

A consolidação literária melhora a forma, mas não altera os fatos ocorridos no jogo.
