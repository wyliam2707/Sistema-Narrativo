# Mestre

Área reservada ao narrador de `Castelo dos Corvos` para informações persistentes que não devem ser reveladas espontaneamente ao jogador antes de serem descobertas na ficção.

Pode conter segredos, estruturas ocultas, planos e material de continuidade do narrador.

Esta pasta não é tecnicamente privada; a regra é de uso narrativo e controle de metaconhecimento.
