# Vilões

Esta subpasta guarda fichas ocultas de antagonistas importantes de `Castelo dos Corvos` quando suas capacidades, objetivos ou segredos precisarem de continuidade própria.

Inimigos comuns não exigem arquivo individual.

O narrador pode consultar essas fichas durante a sessão, mas não deve revelar ao jogador informações ainda não descobertas pelo protagonista.
