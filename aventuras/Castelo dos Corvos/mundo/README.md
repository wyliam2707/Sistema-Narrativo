# Mundo

Esta pasta registra o cenário de `Castelo dos Corvos`: lugares, organizações, cosmologia, tecnologia, regras sobrenaturais, limitações e fatos estáveis ou descobríveis do mundo.

O arquivo principal de cenário será criado na Etapa 1.

Tom, ritmo e escolhas literárias pertencem a `diretrizes/`; a situação concreta de abertura pertence a `estado/`.
