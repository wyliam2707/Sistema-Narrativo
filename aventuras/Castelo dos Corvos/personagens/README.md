# Personagens

Esta pasta guarda fichas estáveis e apresentáveis dos personagens Centrais e Relevantes de `Castelo dos Corvos`.

As fichas podem registrar identidade, CONTROLE, traços, capacidades, personalidade, objetivos e relações recorrentes.

Estados temporários, consequências circunstanciais e antagonistas que exigem sigilo não pertencem aqui; usar `estado/`, `progressao/` ou `mestre/viloes/` conforme o caso.
