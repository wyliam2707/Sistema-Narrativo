# Mestre

Esta pasta guarda material reservado ao narrador.

O conteúdo pode ser consultado para manter continuidade, mas não deve ser apresentado espontaneamente ao jogador nem tratado como conhecimento de Dik Vigarista antes de ser descoberto na ficção.

A pasta não é tecnicamente privada no GitHub; “reservada” significa apenas que seu conteúdo pertence ao lado do narrador durante o RPG.

Subpastas podem ser criadas conforme necessário. Antagonistas importantes ficam em `viloes/`.
