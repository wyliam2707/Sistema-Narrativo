# Mundo

Esta pasta guarda verdades estáveis e canônicas do cenário.

O presente operacional pertence a estado/atual.md.

## Direção narrativa

- investigação;
- comédia romântica;
- romance improvável;
- tom adulto 18+;
- fanfic de super-heróis.

## Escopo inicial do cenário

- a campanha começa restrita ao universo dos Titãs/DC;
- Ravena e Estelar são referências centrais da campanha;
- elementos de outros universos podem ser incorporados futuramente, mas somente quando forem aprovados e se tornarem parte concreta desta versão local do cenário.
