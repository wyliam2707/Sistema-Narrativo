# Campanhas

Esta pasta é a raiz das campanhas atuais do Sistema Narrativo.

Cada campanha deve existir em sua própria subpasta:

```text
campanhas/
├── README.md
├── <nome-da-campanha>/
└── <outra-campanha>/
```

O arquivo `campanhas/README.md` é permanente e não pertence a nenhuma campanha específica.

Sua presença também mantém `campanhas/` visível como pasta própria na navegação do GitHub, evitando a compactação visual `campanhas/<nome-da-campanha>` quando existir apenas uma campanha.

Regras de criação e estrutura:
→ `sistema/criacao/README.md`
→ `sistema/criacao/estrutura-da-campanha.md`
