# Vilões

Esta pasta guarda fichas reservadas de antagonistas importantes, recorrentes ou poderosos quando suas capacidades, objetivos ou segredos precisarem de continuidade própria.

Inimigos comuns não recebem arquivo individual apenas por aparecerem em combate.

As fichas daqui podem ser consultadas pelo narrador durante o jogo, mas seu conteúdo não deve ser revelado ao jogador antes de Dik Vigarista descobrir essas informações de forma plausível.

Uma ficha já definida não deve ser alterada retroativamente apenas para contrariar uma solução válida, recuperar dificuldade ou proteger a trama.

Lúcio Marco poderá receber uma ficha aqui quando passar a importar diretamente na campanha.
