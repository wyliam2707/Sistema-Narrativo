# Exemplos

Esta pasta guarda campanhas demonstrativas concluídas ou suficientemente consolidadas para servir como referência de uso do Sistema Narrativo.

## Exemplo disponível

- `Faroeste Arcano/`

## Como consultar

1. abrir o `README.md` da campanha;
2. consultar `criacao.md` para entender como ela foi montada;
3. ler `diretrizes/`, `mundo/` e `personagens/` conforme necessário;
4. usar `estado/inicio.md` para ver o ponto de partida aprovado;
5. usar `estado/atual.md` para ver o ponto operacional atual;
6. consultar `cronologia/` e `livro/` para acompanhar o que já aconteceu.

Os exemplos existem apenas como referência de estrutura e aplicação das regras.

Não devem ser listados como campanhas ativas em `aventuras/` nem continuados automaticamente.
