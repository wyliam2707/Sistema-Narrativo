# Modelo de Ficha Mínima

Este modelo é indicado para figurantes, criaturas simples e elementos de cena que precisam apenas de informação suficiente para uma resolução pontual.

A Ficha Mínima usa exatamente as mesmas regras do Novo Motor. Ela não cria uma categoria mecânica diferente de personagem.

> **Registre somente o que realmente importa para a função atual da peça.**

# Regra de expansão

Se uma peça inicialmente mínima ganhar importância ou começar a exigir mais informação, sua ficha pode ser expandida para o modelo rápido ou completo.

A expansão não altera quem o personagem é e não concede capacidades novas. Ela apenas registra com mais detalhe aquilo que passou a ser necessário conhecer.

A ausência de uma informação na Ficha Mínima não significa automaticamente valor `[0]`, inexistência ou incapacidade. Significa apenas que aquela informação ainda não precisou ser registrada.
