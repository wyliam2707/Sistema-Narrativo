# Ilusão

**Ilusão [X]**

**Alcance:** Toque → Curto → Médio  
**Área:** Próximo → Curto → Médio → Longo  
**Modo:** Alterar → Ocultar → Criar / Destruir  
**Sentidos:** Geral → Todos  
**Efeito:** Parcial  
**Duração:** Cena → Hora → Dia

## Efeito

Altera a percepção dentro da Área escolhida conforme o Modo configurado.

- **Alterar:** modifica uma percepção existente.
- **Ocultar:** impede que algo existente seja percebido.
- **Criar:** produz uma percepção que não existe.
- **Destruir:** remove uma percepção existente. Não destrói fisicamente o alvo; apenas elimina aquela percepção.

**Sentidos [Geral]** afeta um grupo coerente de sentidos conforme a descrição da Ilusão.  
**Sentidos [Todos]** afeta todos os sentidos relevantes ao efeito.

## Resistência

A Ilusão usa **Efeito [Parcial]**.

Se a Resistência vencer, o Modo é reduzido em um estágio:

**Criar / Destruir → Ocultar → Alterar → anulado.**
