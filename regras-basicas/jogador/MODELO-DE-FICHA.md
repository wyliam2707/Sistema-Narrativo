# Modelo de Ficha

Este arquivo identifica qual modelo deve ser usado durante a criação.

A ficha copiável e preenchível é:

```text
FICHA-EM-BRANCO.md
```

Toda nova personagem começa a partir desse arquivo conforme `1.3-criacao-da-ficha.md`.

A ficha em branco é um **checklist operacional**: ela contém os campos necessários para evitar omissões, mas cada bloco só recebe conteúdo aprovado.

As regras de leitura e construção ficam em:

```text
1.0-descricao-da-ficha.md
1.1-atributos-pericias-poderes.md
1.2-poderes-e-equipamentos.md
1.3-criacao-da-ficha.md
1.4-tracos.md
../nucleo/0.10-mana.md
../nucleo/0.11-vida-e-mente.md
```

Princípios do modelo:

```text
FICHA
→ principal fonte de interpretação da personagem.

ESTADO INICIAL
→ referência estrutural para Vida, Mente, Mana e deslocamento ao começar.

ESTADO ATUAL
→ mudanças temporárias durante a campanha.

LIVROS / CENÁRIO / ARQUIVOS
→ contexto externo que não precisa ser duplicado integralmente na ficha.
```

Personagens simples podem remover campos realmente inúteis na revisão final, mas não devem começar de um modelo diferente reconstruído de memória.

> **`FICHA-EM-BRANCO.md` é a única fonte operacional de estrutura da ficha durante a criação.**
