# Modelo de Ficha

Este arquivo é apenas um modelo de preenchimento. As regras dos campos estão em `1.0-descricao-da-ficha.md`, `1.1-atributos-pericias-poderes.md`, `1.2-poderes-e-equipamentos.md` e `1.4-tracos.md`.

> **Preencher somente o que realmente precisa existir para interpretar, decidir ou resolver a personagem.**

## Ficha rápida

```text

ESTADO DA FICHA: [EM CRIAÇÃO | APROVADA]
Importância:
CONTROLE:

ATRIBUTOS relevantes:

```

## Ficha mínima

```text
# Nome

Importância:
CONTROLE:
Conceito:

Capacidades ou Traços realmente necessários:
```

Campo ausente não significa valor zero. Informação que ainda não precisa existir pode continuar indefinida até se tornar relevante.
