# 0.2 — Rolagens

Status: REFORMULAÇÃO / NÃO IMPLEMENTADO

Este arquivo define **quem executa as rolagens** quando uma resolução mecânica for necessária.

A regra de quando testar, como formar o Valor de Ação e como interpretar o resultado continua em `0.1-resolucao.md`.

## Regra central

Todas as rolagens são executadas pelo `NARRADOR`.

As demais cadeiras declaram intenções, ações, continuidade e oposição conforme sua autoridade, mas não precisam executar procedimentos de dados separadamente.

```text
JOGADOR HUMANO
JOGADOR IA
JOGADOR IA EVENTUAL
OPOSITOR
→ declaram o que suas peças fazem.
→ fornecem suas capacidades pela ficha e contexto.

NARRADOR
→ decide se existe teste.
→ identifica os componentes pertinentes.
→ forma os Valores de Ação.
→ aplica situação e oposição.
→ executa a rolagem.
→ aplica a faixa de resultado.
→ estabelece a sentença.
```

> **A separação entre cadeiras existe para decisão, conhecimento e autoridade. A operação matemática dos dados pertence ao Narrador.**

## Fonte aleatória

Quando uma rolagem for necessária, o Narrador deve usar uma **fonte aleatória real disponível**.

O Narrador não escolhe, ajusta ou inventa um resultado porque ele parece mais interessante, dramático, coerente ou conveniente.

```text
ROLAGEM NECESSÁRIA
→ usar fonte aleatória real disponível
→ aceitar o resultado produzido
→ aplicar a regra correspondente
```

Se nenhuma fonte aleatória real estiver disponível no ambiente de execução, isso deve ser informado em vez de simular uma aleatoriedade narrativa como se fosse uma rolagem real.

## Uma única rolagem por resolução

Quando `0.1-resolucao.md` determinar uma disputa, o Narrador executa uma única rolagem.

```text
2d6
+ Valor de Ação ativo
- Valor de Ação oposto
+ situação, quando houver
```

O lado oposto não realiza uma segunda rolagem.

Isso vale mesmo quando o lado ativo ou oposto pertence a outra persona técnica executada pela mesma IA.

## Fluxo operacional

```text
DECLARAÇÕES
→ JULGAMENTO
→ verificar se existe teste
→ formar Valor de Ação ativo
→ formar Valor de Ação oposto, se houver
→ aplicar situação, se houver
→ NARRADOR executa 2d6
→ calcular resultado final
→ identificar faixa
→ estabelecer realidade
→ narrar sentença
→ registrar
```

## Exemplo

```text
JOGADOR HUMANO
→ dou um soco nele.

FICHA DO ATIVO
Força +3
Combate +1
Superforça +3

Valor de Ação ativo = +7

FICHA DO ALVO
Agilidade +2
Defesa +2

Valor de Ação oposto = +4

NARRADOR
→ executa 2d6 +7 -4
→ aplica a faixa obtida
→ estabelece e narra o resultado
```

O Jogador Humano não precisa calcular a oposição nem executar a rolagem para que sua personagem continue sendo plenamente controlada por ele.

## Regra final

> **As cadeiras decidem. O Narrador julga e rola. Toda rolagem necessária usa uma fonte aleatória real disponível e seu resultado é aceito sem ajuste narrativo.**
