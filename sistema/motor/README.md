# Motor

Status: RASCUNHO / NÃO IMPLEMENTADO

Esta pasta existe para registrar, comparar e testar **ideias de motor e de resolução antes de qualquer alteração nas regras aprovadas**.

Nada dentro de `sistema/motor/` substitui automaticamente arquivos em `sistema/resolucao/`, `sistema/operacao/`, `sistema/personagem/` ou outras áreas aprovadas.

## Objetivo

Usar esta pasta para:

- identificar complexidade e fragmentação do sistema atual;
- propor alternativas de resolução;
- testar simplificações;
- comparar diferentes modelos antes de escolher um;
- registrar vantagens, problemas e consequências de cada proposta;
- amadurecer ideias antes de migrá-las para regras oficiais.

## Regra de trabalho

```text
IDEIA
→ registrar em motor/
→ analisar
→ testar conceitualmente ou em mesa
→ revisar
→ somente depois decidir se será implementada
```

Uma ideia permanecer aqui mesmo que pareça promissora até haver decisão explícita de implementação.

## Princípio

> **`motor/` é laboratório. Não é regra vigente.**
