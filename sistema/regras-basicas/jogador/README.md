# Jogador

Status: REFORMULAÇÃO / NÃO IMPLEMENTADO

Reúne as regras que o Jogador precisa consultar para usar sua personagem durante a sessão.

Inclui, quando forem definidas:

- leitura da ficha;
- uso de Perícias;
- uso de Poderes;
- gasto de Mana e outros recursos;
- combate pela perspectiva do Jogador;
- escolhas e opções disponíveis durante suas ações.

> O Jogador decide o que sua personagem tenta fazer e usa a ficha como interface principal.
