# Mestre

Status: REFORMULAÇÃO / NÃO IMPLEMENTADO

Reúne as regras de julgamento e condução usadas pelo Mestre.

Inclui, quando forem definidas:

- decidir se o resultado é evidente, impossível ou incerto;
- escolher Dificuldades quando houver teste;
- interpretar circunstâncias relevantes;
- aplicar consequências;
- decidir quando não rolar;
- organizar a aplicação das regras sem escolher ações voluntárias pelo Jogador ou pelo Opositor.

> O Mestre julga e aplica as regras. Ele não controla o Opositor.
