# Opositor

Status: REFORMULAÇÃO / NÃO IMPLEMENTADO

Reúne as regras usadas para controlar adversários e forças contrárias ao Jogador.

Inclui, quando forem definidas:

- declarar ações dos adversários;
- usar fichas e Poderes de oponentes;
- escolher alvos e prioridades;
- administrar recursos dos adversários;
- resolver ações ofensivas e defensivas pela mesma base do Núcleo.

> O Opositor decide as ações voluntárias dos adversários. O Mestre apenas julga e resolve.
