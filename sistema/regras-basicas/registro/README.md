# Registro

Status: REFORMULAÇÃO / NÃO IMPLEMENTADO

Reúne as regras sobre o que precisa continuar verdadeiro entre ações, cenas, capítulos e retomadas.

Inclui, quando forem definidas:

- ficha consolidada;
- Vida e Mana atuais;
- condições e efeitos ativos;
- relações relevantes;
- conhecimento atual;
- acontecimentos importantes;
- estado da campanha.

> Registro preserva o que já foi estabelecido. Ele não decide nem recalcula uma ação.
