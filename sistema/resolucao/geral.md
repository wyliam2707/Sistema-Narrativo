# Geral

Status: EFEITO CONSOLIDADO

**Geral** representa manifestações narrativas, utilitárias ou cotidianas realizadas fora do combate.

Geral não possui efeito prático de combate e não substitui um efeito mecânico específico.

## Limites

Uma manifestação de Geral precisa:

- ocorrer fora do combate ou não produzir consequência prática de combate;
- ser coerente com a natureza e o repertório do Poder que a produz;
- não criar uma capacidade nova que o Poder não possui;
- não substituir Dano, Cura, Proteção, Imobilizar, Conter, Controle, Supressão, Informação, Invocação ou outro efeito mecânico específico quando uma dessas funções estiver sendo produzida.

## Exemplos

`Magia → Geral → criar luz`

`Magia → Geral → produzir um som ou voz`

`Magia → Geral → enviar uma mensagem ou estabelecer uma comunicação simples, quando o repertório do Poder permitir`

`Arsenal → Geral → sinalizador`

`Arsenal → Geral → lanterna ou luz de emergência`

`Arsenal → Geral → rádio ou ferramenta comum, quando fizer parte do repertório do arsenal`

## Compatibilidade com o Poder

Geral não significa “qualquer coisa que não esteja nas outras escalas”.

A manifestação precisa fazer sentido dentro do Poder.

Um arsenal pode produzir um sinalizador ou uma luz de emergência, mas não pode produzir um portal apenas usando Geral.

Uma magia pode produzir luz ou comunicação simples se isso estiver dentro do repertório mágico, mas não pode usar Geral para obter gratuitamente uma consequência de combate.

## Fronteira com outros efeitos

Quando uma manifestação inicialmente narrativa passa a produzir consequência mecânica relevante, ela deixa de ser apenas Geral e deve usar o efeito correspondente.

Exemplos:

`criar luz para iluminar uma sala → Geral`

`usar a luz para cegar alguém → Sentidos / Supressão`

`criar uma estrutura decorativa → Geral`

`criar uma estrutura para impedir passagem → Proteção, Imobilizar, Conter ou outro efeito aplicável`

> **Geral descreve aquilo que o Poder pode realizar na narrativa sem gerar uma vantagem mecânica de combate.**

> **A natureza do Poder limita Geral tanto quanto limita qualquer outro efeito.**
