# Proteção

**Proteção [X]**

**Alcance:** Toque → Curto → Médio  
**Alvos:** 1 → 2 → 4  
**Redução de Dano:** 0 → 1 → 2 → 3  
**Escopo:** Específico → Geral → Total  
**Duração:** Cena → Hora → Dia  

**Efeito:** aumenta temporariamente a resistência do alvo, reduzindo o dano recebido que esteja dentro do Escopo escolhido.

## Escopo

- **Específico:** uma fonte ou tipo bem determinado, como fogo, corte ou eletricidade.
- **Geral:** uma categoria ampla, como Físico ou Mágico.
- **Total:** funciona contra qualquer dano.

## Sobreposição

Quando várias Reduções de Dano se aplicarem ao mesmo ataque, use apenas a **maior RD**. Reduções de Dano não se somam.

Exemplo: se o alvo possuir RD 2 contra Fogo e RD 3 Total, um ataque de fogo é reduzido apenas pela RD 3.
