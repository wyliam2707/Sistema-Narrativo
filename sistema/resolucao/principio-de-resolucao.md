# Princípio de Resolução

Status: APROVADO

Este documento define quando o NARRADOR precisa realmente resolver uma ação e quando o resultado já é evidente pelas condições existentes.

> **Resolução não existe para fabricar incerteza. Ela existe para decidir quando mais de um resultado continua plausível.**

## Três estados possíveis

Ao receber as declarações relevantes, o NARRADOR consulta somente o necessário entre:

```text
FICHAS
REGRAS
CENÁRIO
SITUAÇÃO ATUAL
FATOS RELEVANTES
```

Depois classifica a situação em uma destas três formas:

```text
1. RESULTADO EVIDENTE
→ estabelece diretamente.

2. IMPOSSIBILIDADE EVIDENTE
→ estabelece diretamente.

3. RESULTADO REALMENTE INCERTO
→ exige resolução comparativa.
```

## 1. Resultado evidente

Se a intenção é possível, a capacidade é suficiente e nenhuma condição relevante mantém outro resultado plausível, a ação simplesmente acontece.

Exemplo:

```text
JOGADOR
→ abro a porta.

SITUAÇÃO
→ porta comum e destrancada.

NARRADOR
→ a porta abre.
```

Outro exemplo:

```text
JOGADOR
→ ergo a motocicleta.

FICHA
→ FOR [2], suficiente para a ação.

SITUAÇÃO
→ sem oposição ou condição especial.

NARRADOR
→ ergue a motocicleta.
```

A ficha confirma capacidade. Ela não cria incerteza artificial.

## 2. Impossibilidade evidente

Se não existe capacidade, mecanismo ou condição capaz de produzir o resultado pretendido, o NARRADOR estabelece a impossibilidade.

Exemplo:

```text
JOGADOR
→ salto daqui até a Lua.

FICHA
→ nenhuma capacidade que permita isso.

NARRADOR
→ não consegue.
```

> **Resolução não concede uma pequena chance universal a qualquer intenção.**

Uma impossibilidade pode deixar de ser impossível quando a ficção muda e surge um mecanismo real para realizá-la.

## 3. Resultado realmente incerto

Quando, depois de considerar capacidades e situação, ainda existem dois ou mais resultados plausíveis, o NARRADOR precisa resolver a disputa.

Exemplo:

```text
JOGADOR
→ tento alcançar o assassino antes que ele atravesse a janela.

OPOSITOR
→ o assassino tenta escapar.
```

Podem importar:

- capacidades dos envolvidos;
- distância;
- posição;
- velocidade;
- preparação;
- STATUS;
- ambiente;
- tempo;
- regras aplicáveis;
- outras condições relevantes.

Nesse caso, o resultado não é assumido antes da comparação.

## Pergunta central

O NARRADOR pergunta:

> **Depois de considerar as capacidades e a situação, ainda existe mais de um resultado plausível?**

```text
NÃO
→ estabelece o resultado evidente.

SIM
→ aplica a resolução necessária.
```

## A mesma capacidade pode produzir tratamentos diferentes

A existência de uma perícia, atributo ou poder não determina sozinha se haverá resolução.

Exemplo:

```text
Ladrão excepcional
+
fechadura comum
+
dez minutos disponíveis
+
nenhuma interferência

→ resultado evidente.
```

A mesma pessoa diante de:

```text
fechadura de alta segurança
+
alarme
+
trinta segundos
+
guardas se aproximando

→ resultado realmente incerto.
```

A capacidade não mudou. A situação mudou.

## Resolução social

Interação social também segue o mesmo princípio.

```text
JOGADOR
→ pede uma informação banal a um funcionário que não possui motivo para esconder.

→ resposta evidente.
```

Mas:

```text
JOGADOR
→ tenta fazê-lo revelar algo que colocaria sua carreira em risco.

→ existe resistência relevante; pode exigir resolução.
```

Nem toda conversa precisa ser tratada como conflito.

## Investigação

```text
PERSONAGEM
→ procura uma carta na gaveta onde sabe que ela está.

→ encontra.
```

Mas:

```text
PERSONAGEM
→ tenta descobrir qual de vinte funcionários falsificou documentos sem conhecer ainda o método da fraude.

→ resultado não é evidente; exige resolução adequada.
```

## Importância dramática não cria dificuldade

A importância narrativa de uma cena, personagem, objeto ou revelação não altera por si só a resolução.

Uma porta importante continua sendo uma porta destrancada se isso já for verdade.

Um antagonista importante pode sofrer uma consequência decisiva se a situação, as capacidades e as declarações realmente produzirem esse resultado.

> **O NARRADOR não cria obstáculo apenas porque o acontecimento é importante demais para ser simples.**

## Competência deve permanecer competência

Quando uma ação possui:

- capacidade suficiente;
- mecanismo adequado;
- contexto favorável;
- ausência de oposição ou incerteza relevante;

ela deve produzir o resultado correspondente.

Separar intenção de resultado não autoriza criar falha aleatória.

Da mesma forma, capacidade alta não transforma uma impossibilidade em possibilidade sem algum mecanismo real.

## Relação com o ciclo operacional

O OPOSITOR pode mover o cenário antes da resolução.

O NARRADOR então considera esse movimento junto das declarações dos jogadores e verifica se o resultado permaneceu evidente ou se surgiu incerteza real.

Depois que o NARRADOR inicia a resolução, não se adiciona dificuldade retroativa apenas para transformar um sucesso evidente em disputa.

## Regra final

> **Se, após consultar declarações, fichas, regras, cenário e situação, existir apenas um resultado coerente, o NARRADOR o estabelece diretamente. Somente quando dois ou mais resultados permanecerem realmente plausíveis é necessária resolução comparativa.**
>
> **Nem sucesso evidente nem impossibilidade evidente exigem incerteza artificial.**
